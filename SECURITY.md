# Security Policy

Please do not post suspected vulnerabilities, credentials, tokens, private keys, personal data, or other sensitive information in a public Issue.

If GitHub private vulnerability reporting is available for a repository, please use it. Otherwise, contact the FLAMORIS maintainers through an appropriate private channel before disclosing sensitive details.

Non-sensitive security hardening, dependency updates, and general security discussions may use normal GitHub Issues.

FLAMORIS is an open-source project and does not provide a guaranteed security-response SLA or support window. Security fixes generally target the current maintained codebase.

This policy covers code maintained by FLAMORIS. Third-party dependencies, AI models, model weights, datasets, services, and media assets may have separate policies.

---

# セキュリティポリシー

脆弱性の可能性がある情報、認証情報、トークン、秘密鍵、個人情報、その他の機密情報を公開Issueへ投稿しないでください。

各リポジトリでGitHubのPrivate vulnerability reportingが利用できる場合は、そちらを使用してください。利用できない場合も、機密情報を公開せず、適切な非公開手段でFLAMORISのメンテナへ連絡してください。

機密性のないセキュリティ改善、依存関係の更新、一般的なセキュリティ議論については通常のGitHub Issueを利用して構いません。

FLAMORISはオープンソースプロジェクトであり、セキュリティ対応時間やサポート期間を保証していません。セキュリティ修正は原則として現在保守しているコードベースへ適用します。

この方針はFLAMORISが管理するコードを対象とします。第三者の依存ライブラリ、AIモデル、weights、データセット、外部サービス、メディア素材などには別の方針が適用される場合があります。
