# Contributing to FLAMORIS

Thank you for your interest in FLAMORIS.

Issues are welcome from everyone. Pull requests are accepted only from repository collaborators. External users are especially welcome to open Issues for reproducible bugs, unexpected behavior, documentation gaps, and useful feature or architecture proposals. Include the repository/version, steps to reproduce, expected versus actual behavior, and non-sensitive logs or screenshots when they help. If you would like to propose a fix, feature, documentation change, architecture change, or cross-repository work, please open an Issue so the intended boundary can be discussed before implementation.

Please keep changes focused, include or update tests where practical, avoid unnecessary dependencies, and document externally visible behavior.

AI-assisted contributions are welcome. Contributors remain responsible for reviewing, testing, and understanding the changes they submit.

Unless stated otherwise, code contributions are submitted under the Apache License 2.0.

Do not add third-party code, AI models, model weights, datasets, fonts, images, audio, video, or other assets unless their licenses are compatible and clearly documented.

FLAMORIS does not provide guaranteed individual support. Please use the repository documentation, Issues, tests, logs, and source code as primary references. AI-assisted self-support is encouraged.

# FLAMORISへのコントリビューション

FLAMORISに興味を持っていただきありがとうございます。

Issueはどなたでも歓迎します。Pull Requestはリポジトリのcollaboratorのみ受け付けています。外部ユーザーからの、再現できる不具合、想定外の挙動、ドキュメント不足、役立ちそうな機能・設計提案も歓迎します。可能なら対象リポジトリ/バージョン、再現手順、期待した結果と実際の結果、機密情報を含まないログやスクリーンショットを添えてください。修正、機能追加、ドキュメント変更、アーキテクチャ変更、複数リポジトリにまたがる提案は、Issueからお願いします。

変更範囲を絞り、可能な範囲でテストを追加・更新し、不要な依存関係を増やさず、外部から見える挙動は文書化してください。

AIを使ったコントリビューションも歓迎します。提出する変更の確認、テスト、内容の理解については、コントリビュータ自身が責任を持ってください。

明記がない限り、コードへのコントリビューションはApache License 2.0の条件で提供されます。

第三者のコード、AIモデル、weights、データセット、フォント、画像、音声、動画などを追加する場合は、互換性のあるライセンスであることを確認し、そのライセンスを明示してください。

FLAMORISは個別サポートを保証しません。README、ドキュメント、Issue、テスト、ログ、ソースコードを主な参照先として使ってください。AIによる自己サポートも歓迎します。
